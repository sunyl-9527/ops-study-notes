# Prompts 笔记导航

> 本目录用于整理不同学习和工作场景下的提示词模板。

---

## 文档说明

| 文档 | 定位 | 适合场景 |
|---|---|---|
| [devops-prompt.md](./devops-prompt.md) | DevOps 提示词 | 部署、排障、自动化、架构建议、运维脚本辅助 |
| [linux-engineer-prompt.md](./linux-engineer-prompt.md) | Linux 提示词 | 命令解释、系统排查、配置建议、Shell 脚本辅助 |
| [python-learning-mentor-prompt.md](./python-learning-mentor-prompt.md) | Python 学习提示词 | 入门讲解、练习设计、代码调试、知识巩固 |

---

## 使用建议

- 先选择最接近当前任务的提示词模板。
- 使用前把具体环境、目标、报错信息、限制条件补充清楚。
- 如果用于排障，尽量提供命令输出、日志片段和你已经尝试过的步骤。
- 如果用于学习，说明当前水平和希望输出的深度。

---

## 维护建议

- 新增提示词时，文件名建议包含使用领域和版本说明。
- 长提示词建议拆成角色、任务、输出格式、约束条件和示例几部分。
- 经常使用的提示词可以在文件开头补充适用场景和注意事项。
