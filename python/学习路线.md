# Python 运维工程师学习路线

> 学习原则：每个模块都先动手写代码，再看理论。代码文件放在本目录对应子目录下。

---

## 阶段一：系统操作基础（2周）

### 1.1 subprocess —— 执行系统命令
- [x] 已有：`subprocess_learning.py`
- 目标：能用 Python 替代 bash 一行命令
- 知识点：
  - `subprocess.run()` vs `subprocess.Popen()`
  - `capture_output`、`text`、`shell` 参数
  - 实时获取命令输出流（适合长任务）
  - 超时控制 `timeout=`
  - 异常处理 `CalledProcessError`

**练习：** 写一个脚本，ping 一批 IP 并汇总存活/失联结果

---

### 1.2 os / pathlib —— 文件系统操作
- 知识点：
  - `pathlib.Path` 路径操作（推荐，比 `os.path` 更清晰）
  - 遍历目录 `Path.rglob()`
  - 文件读写、重命名、删除
  - `os.environ` 读取环境变量
  - `shutil` 复制/移动/打包

**练习：** 写一个日志清理脚本，删除 N 天前的 `.log` 文件

**新建文件：** `01_sys_ops/file_ops.py`

---

### 1.3 sys / platform —— 运行时信息
- 知识点：
  - `sys.argv` 命令行参数
  - `platform.system()` / `platform.node()`（已用过）
  - `sys.exit()` 带状态码退出

**练习：** 给 ping 脚本加命令行参数 `--timeout`

---

## 阶段二：网络与远程操作（2周）

### 2.1 socket —— 底层网络
- 知识点：
  - TCP 连接检测（端口探活）
  - UDP 简单通信
  - 超时设置

**练习：** 实现一个端口扫描器，扫描指定 IP 的常用端口

**新建文件：** `02_network/port_scanner.py`

---

### 2.2 requests —— HTTP 请求
- 知识点：
  - GET / POST / PUT / DELETE
  - `headers`、`params`、`json` 参数
  - Session 复用
  - 超时与重试（配合 `urllib3.Retry`）
  - 调用内部 API / 监控系统 Webhook

**练习：**
1. 调用公开 API 获取服务器地理位置信息
2. 发送告警消息到企业微信/飞书 Webhook

**新建文件：** `02_network/http_client.py`

---

### 2.3 paramiko —— SSH 远程执行
- 知识点：
  - 密码/密钥认证连接
  - `exec_command()` 执行远程命令
  - `SFTPClient` 文件上传下载
  - 批量多机操作（结合线程池）

**练习：** 批量 SSH 到多台服务器，收集 `df -h` 磁盘使用情况并汇总

**新建文件：** `02_network/ssh_client.py`

## 阶段三：配置与数据处理（1周）

### 3.1 yaml / json / toml —— 配置文件
- 知识点：
  - `pyyaml`：读写 YAML（Kubernetes manifest、Ansible playbook）
  - `json`：内置模块，处理 API 响应
  - `tomllib`（Python 3.11+）：读取 TOML

**练习：** 读取一个 YAML 配置文件，动态生成 Nginx 虚拟主机配置

**新建文件：** `03_config/yaml_handler.py`

---

### 3.2 dotenv / configparser —— 环境配置
- 知识点：
  - `python-dotenv`：加载 `.env` 文件（不把密码硬编码进脚本）
  - `configparser`：读取 `.ini` 格式配置

**原则：** 凡是密码、Token、IP 都走配置文件或环境变量，绝不硬编码

---

### 3.3 csv / openpyxl —— 报表处理
- 知识点：
  - `csv` 内置模块
  - `openpyxl` 写 Excel 报表
  - 常用场景：资产报表、巡检结果导出

**练习：** 将 SSH 批量巡检结果写成 Excel 报表

**新建文件：** `03_config/report_writer.py`

---

## 阶段四：日志与监控（1周）

### 4.1 logging —— 标准日志模块
- 知识点：
  - Logger / Handler / Formatter 三层结构
  - 日志级别：DEBUG / INFO / WARNING / ERROR / CRITICAL
  - 同时输出到终端和文件
  - `RotatingFileHandler` 按大小切割
  - `TimedRotatingFileHandler` 按时间切割

**练习：** 给 SSH 巡检脚本加上规范日志，输出到文件

**新建文件：** `04_logging/log_setup.py`

---

### 4.2 日志解析 —— re / 文本处理
- 知识点：
  - `re` 正则表达式：提取日志中的 IP、时间、状态码
  - 文件逐行读取（大文件不 `readlines()`）
  - 统计 Nginx access.log 中各状态码数量

**练习：** 解析 Nginx access.log，统计 TOP10 访问 IP 和错误率

**新建文件：** `04_logging/log_parser.py`

---

### 4.3 schedule / APScheduler —— 定时任务
- 知识点：
  - `schedule`：轻量级定时（适合简单脚本）
  - `APScheduler`：生产级定时（cron 表达式）
  - 与 Linux cron 的对比：Python 脚本内置定时 vs 系统 cron

**练习：** 每 5 分钟检查一次服务器磁盘，超过 80% 发送告警

---

## 阶段六：并发与性能（1周）

### 6.1 threading / concurrent.futures —— 多线程
- 知识点：
  - `ThreadPoolExecutor`：并发 SSH 多台机器（IO 密集型用线程）
  - `as_completed()` 获取最先完成的任务结果
  - 线程安全：锁 `threading.Lock()`

**练习：** 用线程池并发 SSH 100 台服务器，收集信息

---

### 6.2 multiprocessing —— 多进程
- 知识点：
  - CPU 密集型任务用进程（日志分析、数据处理）
  - `ProcessPoolExecutor`

---

### 6.3 asyncio / aiohttp —— 异步
- 知识点：
  - `async/await` 基础
  - `aiohttp` 并发 HTTP 请求（比线程更轻量）
  - 适合场景：同时探测几百个接口存活

## 阶段八：安全与最佳实践（1周）

### 8.1 密钥与凭证管理
- 知识点：
  - `python-dotenv`：本地开发
  - HashiCorp Vault Python client
  - AWS Secrets Manager / SSM Parameter Store
  - 绝不 `print()` 密码，日志脱敏

### 8.2 输入校验与注入防护
- 知识点：
  - 永远用列表方式传参给 `subprocess.run()`，不用 `shell=True` 拼字符串（命令注入）
  - SQL 用参数化查询，不拼 SQL 字符串
  - 对用户输入做类型和范围校验

### 8.3 异常处理规范
- 知识点：
  - 捕获具体异常，不用裸 `except:`
  - 区分可重试错误和致命错误
  - `finally` 确保资源释放
