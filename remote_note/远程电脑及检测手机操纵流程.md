## 2. 检测手机（jump 检测线路）

### 正常情况

```bash
- 检测手机的窗口全在
- 检测手机的 termux 最后显示的是 socks5 代理信息（用户，密码，端口）
- 使用 ssh 命令，可以正常连接到机器，以伊朗为例（ssh u0_a229@66.93.15.102:20004）能成功连接就行
- 在任意一台机器上执行 socks5 命令，以伊朗为例（curl -v -x socks5://u0_a229:NL2019@66.93.15.102:21004 cip.cc）能反馈IP，和数据信息就行
```
