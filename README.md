# ops-study-notes

个人运维学习笔记仓库，记录 Linux、DevOps、Windows 等方向的学习过程与命令参考。

## 目录结构

```
Notes/
  DevOps/    云计算运维路线、Git、Docker、Nginx、中间件
  Linux/     Linux 命令、云服务器运维、curl、Arch 实验
  Windows/   PowerShell、WSL
  Prompts/   学习与工作场景提示词模板
  Ansible/   Ansible + VMware 实验环境搭建
remote_note/ 远程控制相关笔记（FRP、操控流程）
Codes/       学习代码与路线规划
```
