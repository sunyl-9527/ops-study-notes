---

## 推荐阅读顺序

1. [powershell-notes.md](./powershell-notes.md)
2. [wsl-notes.md](./wsl-notes.md)

---

## 文档说明

| 文档 | 定位 | 适合场景 |
|---|---|---|
| [powershell-notes.md](./powershell-notes.md) | Windows 自动化与运维手册 | 学命令、对象管道、脚本、服务、日志、远程管理 |
| [wsl-notes.md](./wsl-notes.md) | Windows 上的 Linux 学习环境手册 | 学 WSL 安装、发行版管理、文件互通、Docker 和排障 |

---

## 学习主线

```text
PowerShell 基础 -> Windows 运维命令 -> 脚本自动化 -> WSL -> Linux 实验环境 -> Docker/DevOps 实践
```

---

## 实践建议

- Windows 管理和批量自动化优先使用 PowerShell。
- Linux 命令和 DevOps 实验优先使用 WSL。
- WSL 中的 Linux 项目建议放在 `/home/用户名/projects`。
- Windows 文档和笔记可以继续放在当前工作目录中。
- PowerShell 与 WSL 可以配合使用，形成 Windows + Linux 双环境学习路线。
