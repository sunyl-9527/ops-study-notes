# Vim 使用手册

## 模式系统

| 模式 | 进入方式 | 状态栏 |
|------|---------|--------|
| 普通模式 | `Esc` | 默认 |
| 插入模式 | `i` / `a` / `o` | `-- INSERT --` |
| 可视模式 | `v` / `V` / `Ctrl+v` | `-- VISUAL --` |
| 命令模式 | `:` | `:` |
| 搜索模式 | `/` 或 `?` | `/` |

---

## 移动

**基础移动**

```
h j k l     ← ↓ ↑ →
w           下一个单词开头
b           上一个单词开头
e           当前单词结尾
0           行首
^           行首第一个非空字符
$           行尾
gg          文件第一行
G           文件最后一行
5G          跳到第 5 行
Ctrl+d      向下半页
Ctrl+u      向上半页
```

**精准跳转**

```
f{char}     跳到当前行下一个 char
F{char}     跳到当前行上一个 char
;           重复上次 f/F
%           跳转到匹配的括号
*           下一个相同单词
#           上一个相同单词
Ctrl+o      跳回上一个位置
Ctrl+i      跳到下一个位置
```

---

## 插入

```
i           光标前插入
a           光标后插入
I           行首插入
A           行尾插入
o           下方新建一行插入
O           上方新建一行插入
s           删除当前字符并插入
S           删除整行并插入
```

---

## 删除

```
x           删除光标处字符
dd          删除整行
D           删除到行尾
dw          删除到下一个单词
diw         删除当前单词（不含空格）
daw         删除当前单词（含空格）
di"         删除引号内内容
di(         删除括号内内容
```

---

## 复制与粘贴

```
yy          复制整行
yw          复制一个单词
yiw         复制当前单词
y$          复制到行尾
p           粘贴到光标后
P           粘贴到光标前
```

---

## 修改

```
r{char}     替换光标处单个字符
cw          删除到词尾并插入
cc          删除整行并插入
C           删除到行尾并插入
ciw         修改当前单词
ci"         修改引号内内容
ci(         修改括号内内容
.           重复上一次操作
```

---

## 撤销与重做

```
u           撤销
Ctrl+r      重做
```

---

## 可视模式

```
v           字符选择
V           整行选择
Ctrl+v      块选择（矩形）

选中后：
d           删除
y           复制
>           向右缩进
<           向左缩进
~           大小写切换
```

多行同时加注释（块可视）：

```
Ctrl+v → 选中多行 → I → 输入 # → Esc
```

---

## 命令模式

```
:w              保存
:q              退出
:wq             保存并退出
:q!             强制退出不保存
:e file.txt     打开文件
:set number     显示行号
:set nonumber   关闭行号
```

**替换**

```
:%s/old/new/g       全文替换
:%s/old/new/gc      全文替换，逐个确认
:5,10s/old/new/g    只替换第 5-10 行
```

**执行 shell 命令**

```
:!ls
:!python %      运行当前文件
```

---

## 搜索

```
/pattern        向下搜索
?pattern        向上搜索
n               下一个匹配
N               上一个匹配
:noh            清除高亮
```

---

## 分屏

```
:sp file        水平分屏
:vsp file       垂直分屏
Ctrl+w h/j/k/l  窗口间移动
Ctrl+w =        等宽等高
Ctrl+w q        关闭当前窗口
```

---

## 宏录制

```
qa              开始录制到寄存器 a
q               停止录制
@a              执行宏 a
10@a            执行 10 次
```

---

## 配置文件

```bash
~/.vimrc
```

常用配置：

```vim
set number
set tabstop=4
set shiftwidth=4
set expandtab
set ignorecase
set smartcase
set hlsearch
set incsearch
set wrap
syntax on
```
